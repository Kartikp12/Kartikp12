## 👋 About Me

I'm Kartik, a software developer interested in **Applied AI, blockchain technology, and building useful web applications.**

I enjoy working on ideas that involve more than just a user interface — understanding the data, connecting APIs, designing backend workflows, and making the final product genuinely useful.

Recently, I've been spending more time exploring how LLMs and AI agents can interact with tools, retrieve information, and solve practical problems.

- Building AI-powered applications and intelligent workflows.
- Exploring LLMs, AI agents, tool calling, and RAG.
- Working with blockchain data, wallet analytics, and Web3 APIs.
- Developing full-stack applications using JavaScript and Next.js.

I'm always interested in learning new technologies and turning what I learn into something that works.
